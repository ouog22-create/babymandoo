# 우리의 50일 · 촬영 노트

아기 50일 사진 촬영을 위한 레퍼런스 보드와 스토리보드 사이트입니다.

`storyboard.html`은 `ref/`의 사진 28장을 **촬영 구도 7개**로 묶은 별도 스토리보드입니다. 각 구도 오른쪽에서 필요한 소품과 촬영 가이드를 바로 수정할 수 있습니다. 수정 내용은 현재 브라우저에 자동 저장됩니다. `메모 내보내기`로 JSON을 내려받거나 `인쇄 / PDF`로 촬영용 문서를 만들 수 있습니다.

## 실행

이 폴더에서 아래 명령을 실행한 뒤 브라우저에서 `http://127.0.0.1:8765/`를 여세요.

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

설치할 패키지는 없습니다. `index.html`, `styles.css`, `app.js`로 동작합니다.

## 사용

1. **레퍼런스**에서 직접 찾은 이미지를 추가하고 구도, 조명, 소품, 촬영 기기, 보정 방법을 기록합니다. 여러 이미지를 한 번에 고르면 같은 메모를 적용한 별도 레퍼런스로 저장됩니다.
2. 업로드한 사진은 브라우저에서 **밝기·색감·방향**을 계산해 자동 분류합니다. `비슷한 사진` 보기는 색과 화면 배치가 닮은 사진끼리 묶습니다. `내 분류`는 아기 단독, 가족사진처럼 원하는 이름을 직접 입력해 묶는 기능입니다. 이전에 올린 사진은 `다시 분석`을 누르면 분류됩니다.
3. **촬영 스토리보드**에서 컷을 만들고 레퍼런스를 연결합니다. 후지 카메라, 핸드폰 또는 두 기기를 선택할 수 있습니다.
4. 촬영 순서는 컷 카드의 화살표로 조정하고, 준비물 체크리스트와 촬영 모드로 진행합니다.
5. **데이터 관리**에서 이미지와 기록이 포함된 JSON 백업 파일을 내려받거나 복원합니다.

데이터는 현재 브라우저의 IndexedDB에 저장됩니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에는 백업 파일을 내려받으세요. 서버 계정이나 공개 공유 기능은 없습니다.

자동 분류는 사진의 픽셀을 분석하며 외부 서비스에 사진을 보내지 않습니다. 인물, 소품, 조명의 실제 방향, 촬영 기기, 보정 방법은 판별하지 않습니다. 이 정보는 레퍼런스 메모에 직접 기록해 주세요.

## 확인
